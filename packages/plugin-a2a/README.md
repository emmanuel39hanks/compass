# @compass_agents/plugin-a2a

Agent-to-agent coordination: redelegation transport (the delegation 'inbox'), peer/contact registry, and the coordination protocol. Plus an A2A AgentCard builder for cross-ecosystem discovery.

Part of **compass** — personal on-chain agents that grant each other scoped, revocable
authority via MetaMask redelegation (ERC-7710), reason with Venice AI, and execute
gaslessly through the 1Shot relayer.

## Install

```bash
npm i @compass_agents/plugin-a2a
```

> Runs on [Bun](https://bun.sh). For the agent CLI: `npm i -g @compass_agents/cli`.
